**CRON JOBS**

Cron is UTC, not local time	"0 20 * * *" = 20:00 UTC = 6:00 AM Brisbane (AEST, no daylight saving) / 7:00 AM Sydney in summer (AEDT). 
```

┌───────────── minute (0–59)
│ ┌───────────── hour (0–23, UTC)
│ │ ┌───────────── day of month (1–31)
│ │ │ ┌───────────── month (1–12)
│ │ │ │ ┌───────────── day of week (0–6, Sun=0)
│ │ │ │ │
0 20 * * *
```
