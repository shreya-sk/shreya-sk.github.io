# 20-07-2026

**SONARQUBE'S NEW-CODE QUALITY GATE**

Confused why a PR failed the SonarQube gate despite the project's overall code smell count barely moving. Default quality gates only evaluate *new code* against thresholds (coverage, duplication, bugs on lines actually touched) - the overall codebase can be far messier and still pass, as long as nothing new makes it worse.

Actually the right default for a legacy codebase: it stops the bleeding without demanding an unrealistic big-bang cleanup before anyone can merge anything.
