# 29-06-2026

**OCTOPUS VARIABLE SNAPSHOTS**

Changed a project variable in Octopus expecting it to apply to an in-flight release. It didn't - Octopus snapshots all variable values at the moment a release is *created*, not at deploy time. Editing the project variable afterwards only affects releases created from that point forward.

If a live release needs a variable fix, it has to be edited on the release itself (or a new release cut), not the project. Wasted a redeploy learning this the slow way.
