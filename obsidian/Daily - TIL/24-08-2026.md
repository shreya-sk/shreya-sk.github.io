# 24-08-2026

**GRAFANA TEMPLATE VARIABLES ACROSS ENVIRONMENTS**

One dashboard, five environments, used to mean five near-duplicate dashboards. A `$environment` template variable backed by a label query (`label_values(up, environment)`) turns that into one dashboard with a dropdown - every panel's query just references `$environment` instead of a hardcoded value.

Wish I'd done this months ago instead of hand-editing five copies every time a panel needed a tweak.
