# 31-08-2026

**CLICKHOUSE OPERATOR: CLUSTER SCOPE, NOT NAMESPACE**

Installed the ClickHouse Kubernetes Operator expecting a namespace-scoped install like most Helm charts default to. It's cluster-wide by design - one operator watches ClickHouseInstallation CRDs across every namespace, rather than each team running their own.

Good news for the next team that needs ClickHouse: the operator's already there. Just wasn't what I expected walking in, since almost everything else we run is deliberately namespace-isolated.
