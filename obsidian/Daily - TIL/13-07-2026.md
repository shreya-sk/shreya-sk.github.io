# 13-07-2026

**DOCKER LAYER CACHE ORDER**

Rewrote a Dockerfile to `COPY package.json` and run `npm install` *before* `COPY . .` for the rest of the source. Docker caches each layer, invalidating everything below the first changed layer - so if the full source copy comes first, every code change busts the dependency-install layer too, even when dependencies haven't changed.

Ordering steps from least-likely-to-change to most-likely-to-change turned a ~90 second rebuild into a ~10 second one on unrelated code changes.
