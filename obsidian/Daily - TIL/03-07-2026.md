# 03-07-2026

**STATEFULSET PVCs DON'T DELETE THEMSELVES**

Scaled a StatefulSet down from 3 replicas to 1 expecting the storage to clean up with it. It doesn't - PersistentVolumeClaims created by a StatefulSet's `volumeClaimTemplates` are intentionally left behind on scale-down, so a scale-up later reattaches the same volume with the same data.

Good default for anything stateful; surprising the first time if you're expecting Deployment-style ephemeral behaviour. Orphaned PVCs need cleaning up manually if the scale-down is permanent.
